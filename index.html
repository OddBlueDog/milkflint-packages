MilkFlint packages

Kernel module packages (kmods) for MilkFlint. MilkFlint runs its own kernel, so OpenWrt's kmods don't install on it. Each release gets a feed here, built with its images, whose kmods match its kernel exactly.

Installing a kmod

Images with a feed here already list it, so on the router:

apk update
apk add kmod-usb-net-rndis

A feed only fits its own release: after upgrading MilkFlint, install any kmods you had added again.

Licences and source

Each package keeps its own licence (apk info -a <package>); most kmods are GPL-2.0-only, the Linux kernel's. Each feed's SOURCE.txt says where its source is: MilkFlint's OpenWrt tree at the commit it was built from, and OpenWrt's feeds at the commits in its feeds.buildinfo.
